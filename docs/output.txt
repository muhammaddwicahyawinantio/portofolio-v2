I18N

- File diubah: src/i18n/routing.ts (locale order + default + localeDetection: false), src/lib/seo.ts, src/components/layout/LocaleSwitch.tsx (komentar saja).
- Default locale baru: id. / = Indonesia, /en = English.
- Locale prefix: as-needed — ID tanpa prefix, EN dengan /en. /id dan /id/about otomatis 307 ke versi tanpa prefix (bukan 404).
- Locale switch: tidak perlu diubah — sudah generik lewat <Link locale={locale}> dari next-intl, otomatis ikut config baru.
- Bug nyata ditemukan & diperbaiki: next-intl secara default menegosiasikan locale dari header Accept-Language browser. Terverifikasi lewat curl -H "Accept-Language: en-US,en;q=0.9" localhost:3000/ → 307 ke /en — pengunjung ber-browser Inggris tidak pernah melihat versi Indonesia sama sekali, walau sudah default id. Diperbaiki dengan localeDetection: false di defineRouting() (opsi bawaan next-intl, bukan middleware custom). Setelah fix: / selalu Indonesia untuk semua Accept-Language.
